We are announcing a new Crystal release 1.22.1 with important security patches and
regression fixes, as well as some regular bug fixes.

See [the release notes of 1.22.0](2026-10-12-1.22.0-released.md) for all the
changes introduced in Crystal 1.22.

Pre-built packages are available on [GitHub
Releases](https://github.com/crystal-lang/crystal/releases/tag/1.22.1) and our
official distribution channels. See
[crystal-lang.org/install](https://crystal-lang.org/install/) for installation
instructions.

## Changes

### Security: Invalid `SSL_OP_ALL` value across supported OpenSSL and LibreSSL versions

The default configuration for `OpenSSL::SSL::Context` options used outdated options
which weakens security assumptions and may compromise encrypted communications.

See [GHSA-7jw4-6xx8-g2r9] for details.

[GHSA-7jw4-6xx8-g2r9]: https://github.com/crystal-lang/crystal/security/advisories/GHSA-7jw4-6xx8-g2r9

_Thanks, [@ysbaddaden]_

### KernelTLS disabled

After some back-and-forth we disabled KernelTLS by default and it's meant to stay that way.

OpenSSL itself doesn't enable kernel TLS by default either, because it may cause
unexpected behaviour and failures in some scenarios.

We still support kTLS, but you need to opt-in explicitly.

```cr
ctx.add_options(OpenSSL::SSL::Options::ENABLE_KTLS)
```

_Thanks, [@straight-shoota]_
