We are announcing a new Crystal release 1.22.2. This release contains no source changes and is only a package increment.
It was necessary in order to maintain compatibility of the bundled `libgc.a` library.

See [the release notes of 1.22.0](2026-10-12-1.22.0-released.md) for all the
changes introduced in Crystal 1.22.

Pre-built packages are available on [GitHub
Releases](https://github.com/crystal-lang/crystal/releases/tag/1.22.2) and our
official distribution channels. See
[crystal-lang.org/install](https://crystal-lang.org/install/) for installation
instructions.

## Stats

This release includes [2 changes since
1.22.1](https://github.com/crystal-lang/crystal/pulls?q=is%3Apr+milestone%3A1.22.2)
by 1 contributor. We thank all the contributors for all the effort put into
improving the language! ❤️
